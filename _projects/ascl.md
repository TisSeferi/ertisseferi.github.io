Real-time hand gesture recognition system using MediaPipe and custom sequence matching.

## Overview

ASCL is a computer vision project that recognizes American Sign Language gestures in real time. It uses Google's MediaPipe framework for hand landmark detection and applies custom sequence matching algorithms to translate gestures into text.
